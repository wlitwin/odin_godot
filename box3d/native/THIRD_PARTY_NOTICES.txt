Box3D 336263320469e5e9febfe18697ab562488f7e97a
https://github.com/erincatto/box3d
The reproducible driver fetches the exact C engine and preserves its source headers.
No upstream C++ session or godot-cpp code is linked.
The current engine is unpatched. Historical block allocator alignment, compound
geometry alignment and broadphase rebuild patches remain in patches/ for the
July baseline; upstream now supplies the required aligned allocation/packed
geometry and the paired-node broadphase. Their regressions remain active.
Exact engine tree/archive and compatibility patch hashes are in dependency.json.
The driver verifies the complete source inventory before compilation.

rollback-in-a-box 9e1fe882a0ea4eb52e160d5754a752580b4db462
https://github.com/pdaddyo/rollback-in-a-box
The header is copied unchanged. The C shim is adapted by the declared local
patch patches/rollback_shim_box3d_33626332.patch for private recording registry,
replay header and runtime SIMD-width access. The driver reverses this patch and
checks the exact upstream preimage; original and adapted SHA-256 values are in
dependency.json. The original MIT license below remains applicable.
The upstream slot shim is retained as reference compatibility code; its comment
claiming no warm save allocation churn is not adopted as measured evidence.
Private snapshot ownership and normalization live in separate local C modules.
