0 · Quick start

A project is three pieces

  • *.gdextension at project root — loads the CORE dll only (entry_symbol = "odin_godot_init", compatibility_minimum = "4.6"; scripts dll is loaded by the core at runtime, never listed). Keep native entries even for web.
  • scripts/ — one Odin package per directory (same package line in every file of it); subfolders are their own packages in the same dll. Generated per build: odin_godot_scripts.gen.odin per package dir, plus the root's odin_godot_boot.gen.odin + odin_godot_guard.gen.odin.
  • Build → bin/libodinscripts.dylib + bin/libodin_godot.dylib.

Build / run

bash build/build_scripts.sh <project> [scripts_dir]   # scriptgen → *.gen.odin → dlls
ODIN_GODOT_ROOT=…/addons/odin_godot SKIP_CORE=1 \
  bash addons/odin_godot/build/build_scripts.sh .     # addon-consumer form
bash build/build_web.sh <project>                     # one SIDE_MODULE wasm
bash build/serve.sh export_dir                        # COOP/COEP server :8099
make test | make showcase | make web | make bindings

In-editor: Project → Tools → Build Odin Scripts (saving auto-rebuilds + hot-swaps; instances keep state). Fresh dir: Project → Tools → Set Up Odin Scripts.

The one struct + ready ceremony (kboot)

Game :: struct {
    owner: gd.Node,
    ses:   ksess.Session,
    comms: kcomms.Comms,
    boot:  kboot.Boot,
    // entity maps, UI handles, campaign state… NO globals
}
game_ready :: proc(self: ^Game) {
    ksess.session_configure(&self.ses, {tick_hz = 60})
    ksess.session_set_factory(&self.ses, self, make_entity, free_entity)
    ksess.session_set_type_hook(&self.ses, PLAYER_TYPE, self, player_hook)
    kboot.boot_attach(&self.boot, self.owner, &self.ses, &self.comms, kboot.Options{
        title = "MY GAME", msg_kind = MSG_SESSION, latency_env = "MY_LATENCY",
        methods = {"on_host","on_join","on_start","on_chat",
                   "on_packet","on_peer_left","on_net_up","on_net_down"},
    })
}
game_process :: proc(self: ^Game, delta: f64) {
    events, marks, ticks := kboot.boot_pump(&self.boot, delta, knet.now_s())
    if self.ses.is_host { for _ in 0..<ticks { host_tick(self) } }
    for ev in events { #partial switch e in ev { /* game cases only */ } }
}

The 8 @(gd_method) pads are one-liners: wire_receive / session_peer_disconnected / session_client_join / session_peer_disconnected(HOST_PEER) + host/join/start/chat buttons. Never skip the disconnect forwards.

1 · Authoring contract (scriptgen)

Write a clean .odin; scriptgen emits one odin_godot_scripts.gen.odin per scripts dir, a banner-marked section per source (trampolines, command tables, signal emitters, @(init) registration). Export hints are read at runtime by reflection from the same tags.

Header markers (above package; module root or a script subpackage)

//gd:extends Node2DREQUIRED for a script file — Godot base class
//gd:class Nameclass name the loader binds (default: struct name); unique across the whole module tree (root + subpackages), and across modules
//gd:toolruns in editor too (pair with gd.is_editor())
//gd:icon res://p.svgclass icon
//gd:group a bjoin groups at READY (space-separated, repeatable) — no add_to_group ready code

Struct rules

  • FIRST field must be owner: gd.<Base> (offset 0). Engine calls go through self.owner, never bare self.
  • Commands require a net_id: knet.Net_Id field + at least one replicate field.
  • Untagged struct-typed fields are RECURSED: nested tagged fields register with the entity. using embed FLATTENS names; plain embed NAMESPACES (<field>_<leaf>). Generic instantiations substitute through.

Lifecycle procs (name = <struct_snake>_<keyword>)

player_ready / _process(delta) / _physics_process(delta)
player_enter_tree / _exit_tree / _reload   // reload = re-capture cached ptrs after hot swap

delta param optional on process/physics_process; the others take just self. A near-miss name (edit distance 1) warns.

Proc attributes

@(gd_method)callable from GDScript/signals/acid drivers; binds by FIRST param ^Struct
@(gd_rpc) / @(gd_rpc="any_peer,unreliable,call_local,channel=2")implies gd_method; Godot high-level RPC (tokens: authority|any_peer, reliable|unreliable|unreliable_ordered, call_local, channel=N)
@(gd_command)kit/net verb, host-runs; issued from Odin via generated <proc>_cmd (the ONLY role branch lives in gen code)
@(gd_command="predict")client applies optimistically; reject/timeout auto-reverts, reject carries truth. Return bool = APPLIED
@(gd_connect="signal")auto-connect owner.signal → this method at ready (must be gd_method). "Path/To/Node:signal": another node's signal — path resolved like onready= at ready; missing node/signal skips soft + loud. "Bank/Btn%d:sig": probes 0,1,2,… and wires EACH with the index BOUND as the handler's trailing arg (one handler per bank; index 0 required). Scene-unique emitters work: "%SavePanel:saved", "%Inv/Slot%d:pressed"
THE METHOD TRAP (now a build error): a class's proc scan covers its OWN file + HEADERLESS helper files only — an attributed or lifecycle-named ^Game proc written in a file that declares //gd:class Other binds to nothing, so scriptgen refuses the build and tells you to move it to a headerless file. Plain cross-class helper procs stay legal. (Marker-less files are HELPERS — no class identity; any number of classes may extend plain Node.)

Field tags (gd:"…" — first token selects kind)

export[,SPEC…]@export property. One hint: range=0:100:5 · enum=A:B:C · multiline · file=*.png · dir · resource=Texture2D · array=int · dict=String;PackedScene. Plus group=/subgroup=/default=/get=/set=. Typed_Array/Typed_Dictionary derive hints from type.
onready=Path/To/Nodeauto-wired node ref at ready (before gd_connect and your ready); deep paths ok; object-handle field, NOT an export; re-resolved on hot reload. Field typed ^ScriptStruct: resolves node + TYPED script struct in one step (rt.script_of semantics — nil + loud error on a wrong/missing script; reload-safe); engine calls take the NODE — spell self.hud.owner, the ref itself is a compile error (handles are a distinct type). Fixed array + %d template (cards: [9]gd.Button `gd:"onready=Grid/Card%d"`, also [N]^Script): each 0-based index resolves independently. Scene-unique names pass through (%Hud, %Hud/Ammo, %Inv/Slot%d) — segment-start % = unique marker, mid-name %d = template, so %dock stays a name
replicate[,interp][,owner][,wire=f16]kit/net field. interp: remotes lerp (f32/f64/Quat; interp=my_blend custom). owner: owner-authoritative unreliable stream. wire=f16 half-float encode (f32 only); wire=my_codec custom. POD ONLY — handles/strings/arrays rejected at compile with field name. Max 64 fields (fixed array = 1).
signals: gd.Signal0…Signal4 field `gd:"args=a,b"` · gd.SignalN(struct{…})field name = signal name; emit via generated <snake>_emit_<name>(self, …)
/// doc commentabove field = property tooltip; above struct = class doc

Verb / method composition (blocks)

import play "godot:play"          // alias or bare — both compose (bare
                                  // resolves via the package clause)
Runner :: struct {
    owner:  gd.Node2d,
    net_id: knet.Net_Id,
    weapon: play.Gun,             // replicated fields join Runner's descriptor
    sidearm: play.Gun,            // verbs hoist: runner_weapon_fire, runner_sidearm_fire
}

A block command's optional 2nd pointer param (^Runner / ^$E) is auto-filled with the wielder — a pointer, never a wire arg.

Odin-for-this-stack

  • Unused imports are hard errors; @(private="file") for local helpers; proc "contextless" = no allocator/context; proc "c" = engine ABI.
  • context.temp_allocator resets per frame — never stash. Persistent strings: context.allocator, caller frees.
  • Cross-target: when ODIN_ARCH == .wasm32 / when ODIN_OS != .Freestanding; both arms of an if IS_WEB-style constant must compile on both targets.
  • wasm32: Odin int is 32-bit — engine 64-bit values (instance ids) go in i64/gd.Int. No core:os on web.
  • Loop-bound trap: a range expression is re-evaluated per iteration — hoist calls out (for i in 0..<director_tick(...) drains the wave).

2 · gd binding conventions + ergonomics

Conventions

  • Handles alias to Object: any handle passes where Object/Node is taken, no cast; downcast with cast(gd.Node2d)v. Nil-check: cast(rawptr)h == nil.
  • StringName intern trap: NAME args (signal/method/action/group/property) intern a STATIC StringName — pass string LITERALS only, never ctprintf. Dynamic name: new_string_name_cstring(n,false) + free_string_name.
  • Temporaries: PATH/text args may be dynamic (helper builds + frees String/NodePath). Returned String/Callable/Variant from gstr/callable/get_value: CALLER frees (free_string/variant_destroy).
  • Singletons: gd.singleton_engine() / _os() / _input() / _time() / _audio_server() / _display_server() / _physics_server2d()…
  • Printing: format first (fmt.ctprintf→cstring, fmt.tprintf→string) then gd.print / print_str / warn / error / error_str. Panics land as ODIN_SCRIPT_PANIC; crashes symbolize as ODIN_GODOT_CRASH.
  • Threads: everything script-facing is main-thread; rt.script_of main-thread + module-local (nil across modules).

Editor / debug

  • gd.is_editor() gates tool logic. LLDB: Project → Tools → Debug Game (LLDB), or build/debug_game.sh --break file.odin:51 proj. No in-editor breakpoints — AOT native.
  • Squiggles are two-tier: syntax errors from an in-process parse (~0.1ms, first debounce); type errors from an async odin check of the whole package (~0.5s warm, never blocks). Completions ride one persistent warm ols (~20ms).
  • Project settings/env: odin_godot/odin_bin(ODIN), ols_bin, emcc_bin(EMCC), root(ODIN_GODOT_ROOT), export_optimization(ODIN_EXPORT_OPT), show_generated_files.

4 · kit reference (godot:kit/* — knet · ksess · netgd · kboot · kcomms · kcombat · kfx · kui · ksave · kxfer · kinter · kitems · kai · knav · steamgd)

Model: owner-authoritative streams (movement; unreliable last-value, remotes interpolate ~interp_delay in the past) + host-authoritative deltas (everything else; per-tick shadow-diff on reliable) + intent→command→result (predict, confirm, reject-carries-truth, timeout-reverts). Zero role branches in gameplay code. A player IS a reconnect token.

5 · Recipes

The 7-slot recipe (where each part of a behavior lives)

① State — replicated field / play.Machine · ② Cadence — play.Pace (client wall-clock pacer when cooldown < RTT) · ③ Intent — @(gd_command) · ④ Authority — command hook + host_*_tick · ⑤ Prediction — predict body (only what's deterministic from shared inputs) · ⑥ Reconcile — snap on host TRANSITIONS, not every frame · ⑦ Cue — Edge/step → anim/marker/sfx (never decide there). An item's shape IS which slots it skips: gun fills all 7; revive skips ⑤⑥; mob brain is host-only (skips ③⑤⑥); match phase = one singleton Machine; pickup = proximity scan (no command).

Replicated entity

Predicted verb + cross-entity hook

@(gd_command = "predict")
crate_loot :: proc(c: ^Crate) -> bool {          // gate BEFORE issuing too
    if c.slots[0].item == kitems.ITEM_NONE { return false }  // reverts everywhere
    c.slots[0] = {}

}

Bullets — projectiles are never entities

  1. Cast = predicted command (cooldown/ammo inside it). Shooter draws NOW: kfx.tracer_add(&t, world, fire, "·", ksess.session_tick_hz(&ses)).
  2. Host (hook, gated on ok): simulate authoritative projectile (append to pool; kcombat.leash the claimed origin) + fire_announce.
  3. fire_listen draws everyone else's; own echo auto-skipped.
  4. Host tick: pool_tick(&flying, self, targets, on_hit, on_expire) — only host's projectile hurts.
  5. Impact NOW on each screen (sparks + php_note_hit); truth heals a miss later.
Shooter-stamp rule: client-PREDICTED fires (guns/lobs/cones — caster already drew) are announced with the CASTER stamp; HOST-AUTHORED instants (novas/zones/buffs/reactions + re-announces) must stamp the HOST — fire_listen drops shooter==me, and a caster-stamped instant leaves the caster blind to his own visual.

Statuses + combo rulebook (scrapyard pattern)

  • fx: [2]kcombat.Effect `gd:"replicate"` on mobs AND runners; every screen tints off effect_of; host alone ticks decay + dots.
  • apply_status checks the COMBO table before stacking: (present, incoming) → detonate / transmute / spread; consume flag; outputs re-enter (chain cap ~4; cycles fizzle). Same-status pairs hit the table too — free design axis.
  • Reactions are positional + indiscriminate (friendly fire is a design decision); aimed instants keep targeting.

Data-driven defs (.tres → wire → mods)

  1. Author shapes as custom Resources (//gd:extends Resource, export hints) → designers edit .tres in Inspector.
  2. Boot: scan res://data/*, flatten via rt.script_of(res, Def) into POD row tables placed by declared wire id (later filename wins = override).
  3. Host publishes merged tables as the WORLD entity's blob (session_set_blob) — spawn tuple/joins/backups/saves carry it; clients need no data files; Ev_Blob_Changed is the one client hook.
  4. Mods = user://mods/*.json overlay (whole-row replace), host-only files reach every screen. Ordered rows: numbered filenames = precedence, mods append.

Downed / revive

Host migration / succession

  1. Host: session_set_backup_blob (director clocks, campaign) — snapshots flow to a backup target automatically.
  2. On Ev_Backup_Target{player}: host names how to reach the heir — session_set_successor_info(addr:port | "web" | room code). WITHOUT info, SES_SUCCESSOR is never broadcast.
  3. On Ev_Succession{successor}: bearer = takeover (session_backup_parts → wipe local census → raise transport → session_host_resume); others = chase (reconnect to info; event re-fires per failed attempt → retries free). Copy session-owned strings out BEFORE *_start frees them.
  4. Web chase: the torch names TOMORROW's room — host mints a reservation code, heir hosts under it, survivors knock every ~2.5s.
  5. Reclaim rule: a token only reclaims a DEAD seat; a live match demotes to fresh join (doppelgänger rule — tabs share user://).

Dedicated server

boot_serve(port,name) / session_host_start(dedicated=true): authority-not-player. Skip it when spawning avatars (if p.dedicated {continue}); session_count(players_only=true); succession never arms (a server restarts).

Web co-op

  1. begin_host_web(&wire, "wss://…/rtc", name) — relay assigns the room code async: surface gd.webrtc_room_code when it lands; web_poll every frame.
  2. Same session code as native (transport-agnostic). N-peer star: host + 7 joiners; joiner↔joiner traffic relays through the host.
  3. Export: build_web.sh, SharedArrayBuffer headers, keep native .gdextension entries. Payloads >16K go through kxfer.

Lag-comp hitscan (lance/mender pattern)

Host keeps play.Trail per target (trail_note each tick). On a hitscan command: rewind targets to the SHOOTER's render time (tick − interp_delay·hz), segment-vs-circle judge against rewound positions, apply damage/heal to live state. Shooter's crosshair truth ≈ host judgment.

Shared-seed procgen

Replicate the SEED, not the scenery: every peer grows identical decoration locally. INTEGER math end to end (splitmix32) — floats diverge (FMA/libm/fast-math). Acid asserts a checksum on every peer. Art law: rosters index by k % len — never delete entries, swap art IN PLACE (same index, same footprint) or every seeded layout reshuffles.

6 · Gotchas

Replication / netcode

  • Deltas carry STATE, not events — a byte flipped 1→0 inside one tick never ships. Edges need dwells; use seq counters for pulses (dash_seq).
  • Only the owner moves the owner — knockback/respawn are replicated state the owner reacts to. Jumps are teleports (session_teleport) or remotes slide.
  • Two timelines: my sim presents NOW; remote causes present at render time (session_present(mine,…)); no-spatial-cause facts (scoreboards) present wire-fresh; global transitions after a dwell.
  • The pacer: cooldown < RTT can't be paced by replicated cds — pace the trigger on the client's wall clock (play.Pace), host still gates.
  • Tick loops, not frames: anything counted in ticks lives in the for _ in 0..<ticks loop — per-frame countdowns track fps (a 120fps unthrottle halved a 3s countdown). Read session_tick_no, never hand-roll a counter (diverges on resume).
  • Prediction gates twice: gate before issuing (refused predictions still ride the wire) AND in the command body.
  • registry_get pointer valid only until next insert/remove; Ev_Resynced ⇒ re-seed Edge scratch or missed changes present as fresh events.
  • Stat_Col on clients is zero-value (column 0 = ping) — resolve by name with session_stat_find.
  • Replicated-state UI echoing MY change needs a prediction read (2Hz stats cadence looks broken otherwise — muster row pattern).
  • Jam/crit rolls: seed from MONOTONE counters (lifetime spent), never cycling state (salt,ammo re-rolled the same verdicts every mag).
  • Reconnect identity: a known token only reclaims a DEAD seat; live seat ⇒ fresh join (doppelgänger). Every identity added to a reclaim table must be audited against the still-connected rule.
  • Localhost inverts web disconnect ordering (ws instant, DTLS lingers) — a localhost pass proves ONE ordering of a signaling-vs-media race; production dies media-first. Gate every signaling callback on instance-id liveness.

Engine / UI

  • RigidBody ignores node transform writes — pose via PhysicsServer body_set_state (Puppet does).
  • Control anchors bind to a Control parent or the viewport under a CanvasLayer; under a plain Node they bind NOTHING (top-left hug). Containers overrule set_size — custom_minimum_size is the contract.
  • TextureRect default expand_mode grows the control to its texture — set expand_mode=1 for fixed panes. Labels auto-grow to min size.
  • Scene sample text is for the EDITOR — ship such nodes visible=false; the frame feed shows them.
  • Marker-less files are HELPERS — no class identity (pre-2026-07 loaders bound them to THE Node class, forcing one-Node-class packages). Verify editor-facing work with godot --headless --editor --quit (catches warnings the game run never shows).
  • CanvasLayer children draw above world z-index — UI on a layer, never trust entity z against it.

Web / wasm

  • Odin int is 32-bit on wasm32 (i64 for instance ids); no core:os (gd.singleton_os()). core:time is STUCK on wasm — knet's clock auto-swaps to the engine's at wire_attach (knet.set_clock), so kit pacers/tickers just work; only game code reading core:time directly still needs Godot's clock.
  • Bundled-font glyphs only (· • *) — system-font fallbacks render as boxes.
  • WebRTC message cap ~16K — big payloads through kxfer. TURN needed for symmetric NAT. web_poll every frame.
  • COOP/COEP headers required (serve.sh; itch = SharedArrayBuffer checkbox). Pin Emscripten (4.0.20 known-good).

Process / tooling

  • Editor reload builds race CLI builds — PID-scoped temps fixed it, but gates still want the game's editor closed (auto-save can stomp the tree: check lsof on mystery reverts).
  • CONSUMER core path: an addon-layout project loads the CORE from addons/odin_godot/bin/<platform>/ — build_scripts.sh now detects the layout and publishes the core there automatically (kit/play/scriptgen changes ride the scripts dll and never needed this).
  • build_scripts.sh publishes atomically (temp + mv) — an interrupted rebuild never removes the previous dll. Deleted .odin files: the deletion probe spots the orphaned generated section every ~2s and rebuilds to sweep it.
  • Working directory persists across shell calls — background launches inherit the LAST cd; write multi-line commands with the cd on its own line.
  • Verdicts from literal log lines, not exit codes (a FAIL run can exit 0). Count retry attempts (grep -c attempt) — retries mask flakes.
  • Regex sweeps that abstract a pattern must exclude the new helper's own body (self-recursion) — write the helper AFTER the sweep.
  • zsh: backticks command-substitute inside double-quoted git -m; == expands; single-quote message bodies.
  • Module rule: no imports between modules (a package in two dlls silently forks its globals); cross-module = engine-mediated by name. One exemption: res://shared/ packages (types/constants/pure procs, verified state-free) — but a shared edit rebuilds EVERY module.
  • Subpackages: annotated classes may live in scripts/<sub>/ (own package, same dll, attachable from there). Kit declarations stay in the module root; a subpackage importing the root is a cycle (refused).
  • Print-receipt tests can't see ART — presentation changes need a viewport-grab probe (SY_SHOT pattern: env path + save viewport texture every 2s).

Kit-specific traps

  • Block imports: alias and bare both compose (bare resolves via the package clause). Pre-2026-07 scriptgen skipped bare-import embeds silently — alias there.
  • App-tag collisions are LOUD now — session_app_route asserts when a tag is re-routed to a different handler (same-route re-registration stays legal). Still pick explicit tag bytes (comms 0, fire 1, xfer 2, vault 3…).
  • comms_destroy before session; Ev_Line.text and session_blob return VIEWS — copy to keep.
  • kick: kboot.boot_kick(&b, player, ban) does both halves (seat + deferred socket close after the kicked message flushes); hand-rolled = session_kick + wire_drop.
  • steam lobby_joined fires for the host's own lobby (guard owner==me). Steam can't be verified headless — live checklist.
  • Kit-source changes need the KIT suite re-run, not just the consumer's acid.
