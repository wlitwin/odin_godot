# API reference

Browse the [online API reference](https://wlitwin.github.io/odin_godot/api/) for
package indexes, public types and functions, source signatures, member notes,
overloads, and implementation links.

The website generates these pages from the SDK source. The online reference
follows `main`; check the source bundled with your addon for the declarations
in your installed revision. For setup and lifecycle guidance, start with
[the documentation index](../index.md).
