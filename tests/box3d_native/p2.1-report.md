# P2.1 shared native contract and helpers

Task `t_7f69d1f269ae48db`, board `b_cdde1cdfea104035`, worker
`box3d-contract`, recorded 2026-10-30. Supplied task/worker/token were verified
with `task show`; no other card or agent was started. The shared contract is
[framework-contract.md](../../docs/design/box3d/framework-contract.md).
Kit and Replay development stayed with their respective workers; this card
changed only its shared native/Odin helper, test and contract scope.

Implemented checked world-independent Body/Shape/Joint allocation keys and
resolution, actual world counters, and immutable historical Body_State reads
from owned snapshots. The cache survives source destruction, is shared by
explicit clones, uses binary search/bulk copied reads without scratch worlds or
allocations, and is bounded to 65,536 live bodies for the general native helper.
Alpha admission remains 35 total bodies. Cache bytes and metadata are charged to
existing wrapper/storage counters. At 35 bodies/H=128, cache payload alone adds
358,400 bytes plus Resource metadata to the previously measured representation.
Its integration timing/resource envelope therefore needs P2 measurement.

Added structural `shape_key_from_handle` for copied sensor-end IDs after shape
or world destruction. It does not claim liveness; checked `shape_key` and
`shape_resolve` retain their live/destination checks. Added native size/offset
checks for Body_State/World_Counters, Odin typed keys, shared stage
open/world/swap/discard helpers, alpha observations and hard count/age/history/
requested-memory admission, including detached `alpha_memory_check` after all
execution/provider objects are destroyed. Per coordinator steering, elapsed
work and over-target flags are observations for integrated acceptance tests;
4 ms wall-time overages never change admission or simulation transitions.

The complete normalized stream stays version 2/coverage
`ogb3-d421e45c-solver-v2`. `state_dump.c` is byte-identical to the approved Gate A
implementation (SHA256
`a8eea34b83fadd953f7eeff91bd08f0de0921ef59371d58c29bcef0f5ba219c0`).
The dependency pins and all three source patches are unchanged. New helpers are
local same-build/same-target operations, not a portable image or wire format.

Executed shared-helper validation:

- Exact build-driver Debug and Release on macOS arm64: native CTest 3/3 each.
- Full AddressSanitizer+UndefinedBehaviorSanitizer, alignment included and no
  exclusions: native CTest 3/3.
- Actual Odin helper lifecycle: 9/9 in both macOS configurations.
- Linux x86-64 under the existing Debian/Podman/Rosetta environment: native
  CTest 3/3 and Odin 9/9 in each Debug/Release configuration. This is target
  execution evidence, not native Linux hardware throughput.
- New controls cover canonical/malformed/stale keys, all three checked
  resolutions, retired sensor IDs, unchanged failure outputs, clone/source
  destruction, bulk read capacity, derived-cache capacity, all five capture
  allocation failures plus restore Lease failure, zero per-read allocation and
  world creation, stage ownership, detached memory admission, numeric overflow,
  actual body caps, ages/history and observational clock over-target flags.
- Native and wrapper tracked live bytes return to zero. macOS `leaks` reports
  zero leaked bytes. Debug/Release DSO exports exactly match all 74 declared
  `ogb3_` functions; dependencies remain C-only, with no Godot/C++ runtime.
- Default native-free SDK checks: Kit `tests/kitsim` 56/56, Replay
  `tests/replay` 33/33, and Replay `tests/replay_schema` 28/28 pass without a
  Box3D library definition/link.

One first Linux CTest invocation stalled in the emulated harness with its
lifecycle child already exited 0/zombie; that worker-owned ctest was terminated.
The binary passed directly, and coherent Debug/Release retries with a 30-second
CTest timeout passed 3/3. No solver assertion, failure or sanitizer exclusion was
used to turn that harness issue into passing engine evidence. The macOS Odin
linker warns that native objects target macOS 15 while Odin requests 14; these
executed tests ran on macOS 15.8 and do not certify macOS14 deployment.

Both sibling interfaces were coordinated early. The contract separately defines
Kit's complete lane/Side/field ownership and correction publication, and Replay's
existing Timeline participant, complete checkpoint, scoped execution and nested
savepoint requirements. It requires initial dynamic-count verification from
actual first snapshot states, fixed predeclared assets/contract identity,
reservation preflight and post-stage resource observations, no missing-history
live fallback, no native dependency in default cores, and no elapsed-time
simulation admission. Actual sibling implementation/transaction correctness and
integrated performance belong to P2.2/P2.3/P2.4; their results are not inferred
from these helper tests. The independent final Kit concrete Debug smoke also
passes 3/3 after clarifying exact repeated-confirmed no-op versus required
unconfirmed age-nine repair; further adapter coverage remains with its owner.

The concrete one-DSO Godot policy covers platform artifact/rpath selection,
serialized calls, unload ordering, and producer-module callback/type-info
lifetimes for detached checkpoints. Actual two-module create/read/step/clone/
restore/release/reload execution remains later build/export evidence. Static
standalone tests do not certify that production boundary.
