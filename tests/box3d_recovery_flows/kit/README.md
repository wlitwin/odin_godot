Three public Kit recovery groups reuse `tests/kit_box3d_net` Box,
Session, Native/provider setup and diagnostics, and `tests/kit_world_protocol`
packet ownership/real Lane drive helpers. They add no Session, parser, private
head/scope setter, solver or netcode implementation. Root runs all compilation
and execution. Actual Native/wrapper/provider and diagnostic-owner baselines
are checked after typed teardown. These are standalone/NilOwner public controls;
managed SDK/export evidence is separate. All three groups passed on native
macOS arm64 and translated Linux x86_64; see the [bound report](../report.json).

1. The authority and existing driver advance to12 before a real Session
   spectator enrolls. Its actual Welcome adopts complete5 without historical
   FX. The spectator consumer uses **only `lane_frame(0)`**; its sampler fails
   if invoked, no proposal is emitted, and authoritative accepted/signature
   catch-up keeps head equal to confirmed through24 with exactly the new
   eligible FX. This is an explicitly tested consumer policy. Generic World
   positive Frame is not inherently disabled by the Session spectator flag.
2. A real Session disconnect retains the token identity; a new transport peer
   reclaims it and receives a fresh World bootstrap. Actual captured old INPUT
   packets are replayed from both old and replacement peer contexts; old
   ACCEPTED/SIG/explicit diagnostic chunks are replayed to the replacement.
   Complete5, bootstrap, frontiers, effects and bounded ownership must stay
   unchanged. Fresh actual controls/Spawn then confirm once; repeated genuine
   final traffic cannot repeat eligible FX. No separate World ACK is invented:
   this seam owns no application final-signature ACK. Fresh logical drivers
   after GO remain the example's explicitly unsupported immutable-contract case.
3. An actual dense32 pair retains a partial explicit diagnostic Correction,
   requests Reset publicly, and receives old queued traffic plus a conflicting
   duplicate Reset fragment. Last published complete5 remains intact until the
   full valid replacement. Genuine future Host control/signature traffic and
   the future full5 oracle are retained before the source Native world/Session/
   catalog creator are destroyed. The receiver then imports source-free Reset18
   and confirms those real future authority rows through24 with one newly
   eligible FX. It does not pretend a destroyed Host received new proposals.
   Replacement drivers' fresh proposal admission is covered by group2.

The only deliberately malformed bytes are a bounded payload-bit change in an
actual copied chunk. Existing public packet helpers preserve all other bytes;
no synthetic scope, signature, generation, peer admission, receipt or success
counter is assigned. Partial/corrupt/stale rejection retains its actual outcome
until complete valid recovery succeeds. Existing World2, P6.2/P6.3 and legacy
migration evidence remains unchanged; these source files are not test PASSes or
whole-P6.4 acceptance by themselves.
