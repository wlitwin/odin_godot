# Replay recovery flows — four public groups

All four groups passed on native macOS arm64 and translated Linux x86_64; the
[bound report](../report.json) retains failed compile/setup runs and their finite
corrections. No production amendment was needed. Current Release Native + the actual
shared `box3d_common.Game` and Replay adapter/codecs are used over public Memory,
static/nil-owner scope. This is not Core/SDK/export, hardware or CPU qualification.

The groups cover progressed late driver join; a late observer alongside a real
driver; same-token endpoint departure/replacement and old packet isolation; and
actual beyond-H128 receiver loss followed by interrupted canonical recovery.
No head, ready, generation, notice or confirmation field is assigned. The real
Host, driver, observer and replacement use distinct public endpoints. Memory time
advances in checked steps no larger than 10000; H128/prediction8/repair8, Native
35/35/32/one-joint/eight-assets and64MiB are unchanged. Four-body profiles are
used first; the hard-resync group uses the allowed32-body profile and requires an
actual multi-part transfer rather than manufacturing padding or a smaller wire
chunk limit.

Canonical five-part bytes are compared using the existing bounds helper. Future
controls are read from the actual committed authority Batch for both seats;
eligible Motor action/outcome and confirmed gameplay occurrences must appear
exactly once and match real authority events. The observer's public step/action
calls must refuse without transmitting or advancing it; it has no speculative
FX or prediction repair. These assertions do not invent effects lost outside a
canonical recovery baseline.

Reconnect captures real input, signed facts, chunks and the appropriate ACK
before actual endpoint close. A new peer uses the same token/seat and a genuinely
new authority generation. Reopened old-peer traffic and old-scope traffic on the
new peer exercise separate sender/scope checks. Stale signed facts/chunks are
also replayed from the authority and a foreign peer. Raw packets remain owned and
hash-checked until cleanup; no private Kind/packet parser or fake ACK is used.

Hard resync is triggered by consuming/discarding real authority traffic, then
public pumping observes the actual Resync notice and correlated Welcome. A real
prefix, identical duplicate, conflicting payload and complete corrupted candidate
must preserve published complete5/frontiers/held/pending/effects. Public schema
envelope helpers re-encode a one-byte payload mutation; no wire layout is copied.
Actual owned admission is checked and duplicate parts cannot add another charge.
A complete original replacement then admits valid future controls/eligible FX.
The original Native world and initial checkpoint creators are destroyed after
the complete authority owns its clone; immutable codec/catalog ownership stays
alive until all recipient checkpoints and Timelines have been checked-destroyed.
All Native/wrapper/provider/host owners must return to zero.

Manual Replay UI Reset remains unsupported: no private `client_resync` call.
`session_open_complete` is authority-only; Client/Observer SDK roles use ordinary
`session_open`. Authority handoff/departing-host recovery remains separate
existing evidence, not a new mechanism or claim in these four tests.
