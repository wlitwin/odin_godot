The native host/client/observer fixture suppresses only the client's protocol-7
Observation packets. Reliable actions, facts, snapshots and admission continue.
The client walks locally to the chest while the authority still has its spawn
position. An explicit O1-compatible accepted-pose request is refused; the normal
UI's contextual request takes the three gems. All participants verify inventory
conservation and that the action did not move the accepted avatar. Resuming the
pose stream then moves it normally. No running game world is edited by the driver.

The wrapper borrows/forwards the original transport callbacks, including connection
generation. A compile-time protocol assertion protects its test-only packet-kind
constant. The legacy comparison bypasses only the UI context-capture helper and
uses the ordinary reliable action protocol; it is not an archived O1 executable.

Model tests additionally cover newer motion overtaking an action, original Kit
range/leash math, stale object/life/epoch rejection, context-preserving checkpoint
serialization, refused old-epoch pending work, and exact O1 conversion. The genuine
O1 pending checkpoint was captured before changing its action schema. Its world,
controls, peer/action frontiers and accepted-pose interpretation must survive.

The ordinary owner-profile native/browser migration/save suites remain separate
regressions. This gate does not prove all original-game rules, public-network
behavior, or competitive validation of a claimed pose.
