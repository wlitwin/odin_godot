# Dockyard prototype checks

`assess.py --case ABS_SAVED_CASE --out NEW_DIRECTORY` reads saved ordinary
Host/Client output. It requires each real producer log to equal its recorded
events, two positive committed per-seat control counts, matching actual final
five-part bytes, real terminal signatures, confirmed cargo delivery/cue and
checked allocation/owner teardown. It executes no game and preserves the source
report, including the older sample controller's retained heuristic failure.

`visual_smoke.gd` is an actual-window test script. It instantiates the normal
scene, reads its public copied presentation, saves the rendered viewport and
checks public close. It proves a rendered14-body frame, rather than human
gameplay or network acceptance. Its input suppression is selected only by
`DOCKYARD_AUTOCAPTURE=1`.

The prototype report records ordinary builds, original unsuccessful carrying
attempts, the continuous-ramp geometry decision, actual first-cargo success and
the final native screenshot. Browser integration and final sustained/performance
qualification belong to later showcase cards.
