# Evolution generator fixtures

The Odin files in this directory preserve the output of `evolution.freeze` and
`evolution.scaffold`. `contracts_test.odin` regenerates the source and compares
the exact emitted bytes, alongside the canonical JSON contracts. The conversion
scaffold deliberately refuses to convert until its new defaults are reviewed.

Scrapyard's `shared/revisions/content49` and `content50` directories contain the
corresponding frozen historical types, independent of the live content package.
Their source and these fixtures were captured in `af097411`. The formatter-only
changes from `281e06e8` were reverted to retain those original generated bytes.
Both trees are excluded from the repository formatter. Regenerate and review an
intentional generator change together with these fixtures; do not hand-format
them or replace the historical schemas with current game types.
