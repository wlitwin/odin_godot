# Prospective Kit intent contract V2

V1 is the default when `READY.intent_contract_version` is absent or integer1.
Its original `old_head < old_due <= baseline` rule remains unchanged. Unknown,
boolean, string, or floating versions reject. Historical records and failed
cases are not upgraded or reclassified.

Fresh V2 READY declares integer2, the existing `outside_sim_catalog_class1`
source, and Scheduled action timing. Root's prelaunch controller argument is
`--kit-intent-contract 2`; closed LONG evidence additionally requires the actual
`report.plan.kit_intent_contract` to be integer2 and both READY records to agree.
Absent historical plan fields mean1. Replay cannot opt into Kit2. The LONG
policy ID, fixed thresholds, phases, bounds and plan format are unchanged.

Every V2 `INTENT_REBASE` must declare integer2 and provide actual pre-mutation
`pre_attempted`, `pre_published`, `pre_transported` booleans false and integer0
`pre_attempt_tick`, `pre_attempt_head`, `pre_packet_head`, `pre_row_sequence`.
`pre_recovery_serial` equals this plan's last validated reset scope, initially0.
`player` matches READY.me; `class` is integer1; epoch, seat, session generation
and actor context must match. Prior ATTEMPT or ISSUED records pin the identity
even if a later producer record claims false flags.

The tracked old current due must be at or below the validated Reset baseline;
the checked new due is exactly baseline+1 and within the declared target. The
original scenario due stays immutable. One preceding same-episode RECOVERED
must match epoch, generation, old/new watermarks, previous head and baseline,
with complete publication and a valid retained signature. RECOVERED is the
existing source-bound observation emitted only after ready/watermark/signature
checks; numeric proximity or an ordinary catchup is not a substitute. Multiple
unattempted plans may reference the same Reset; no per-plan lookup is invented.

The existing sample+8, sampled_head+1, packet range and publication/transport
checks remain. V2 additionally rejects duplicate or reversed per-seat issued
sequences. This is a prospective external-intent contract, not a Kernel promise,
old-failure explanation, acceptance waiver, or a change to physics/network limits.

The new Python controls contain synthetic signatures and metadata only. They
do not claim a live Lane, SDK ownership, admission, state match or Godot result.
