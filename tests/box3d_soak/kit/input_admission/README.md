Two deterministic public Session/Lane admission arms using the existing generic
four-body Spawn fixture and owned in-memory Parcel delivery queues. Static
Native9c66/nilOwner is descriptor/resource diagnostic scope, not SDK32 or GateB.

Timely delivery submits Spawn before authority tick1. Settled-late delivery
first exposes the real authority None decision to the client, which still
samples/sends the identical local Spawn bytes; authority correctly ignores that
late proposal. The public checkpoint Side `last_action[1]`, births/extra-body
state, occurrences, actual effect callbacks and all five canonical parts prove
the different dispositions. No caller debt, policy, clock, head or ACK setter.

`python3 tests/box3d_soak/kit/input_admission/run.py NEW_SCRATCH_DIRECTORY`
performs one small compile/test transaction, retaining the exact packet bytes,
both endpoints' five-part bytes, source/native/binary references and failures.
