Two groups, uncompiled/unrun. Root owns the actual baseline and any later
production-path amendment. Run with the current Release Native archive and the
ordinary `godot` Odin collection; no old benchmark, policy or source is edited.
This is real Native/shared Box3D Game + Replay complete physics over Memory,
static/nil-Owner scope, not an actual SDK/export/CPU/impairment result.

1. A genuine current-generation/serial ordinary Snapshot is captured from the
   actual Host transfer and public Memory transport. The real signed facts are
   delivered first. Only a held control is changed to structurally valid i16
   `101`, outside the actual common model's `[-100,100]` bound. A public complete
   re-encode keeps all original canonical five parts byte-exact and produces
   valid integrity/digest/chunks. The candidate must reject before pending,
   publication, held controls, frontiers or effects change. Then the unchanged
   captured Snapshot and a further real authority step must still succeed.
2. The actual shared Game receives either `retired_count=9` for its eight-entry
   array, or one active retirement row with zero shape/lifetime references.
   A real public peer timeout/reconnect/Hello produces a replacement Welcome;
   no scope/head/ready flags are assigned. Both metadata and canonical Game
   bytes are re-encoded consistently with genuine Native solver/Side/cache/
   occurrence data. Reject before installing the new Game/scope is required.
   A fresh genuine unmodified Welcome restores a safe control before resumed
   work, including on the expected old RED. The initialized receiver is a public
   spectator, so invalid retirement data is never executed merely to cause OOB.

or parsed here. Bounded malicious scalar mutations use the *actual public*
compiled schema field paths/widths/offsets and public scalar encoders.

actual Native checkpoints and captured envelope kind/scope through the real
authority endpoint. This deliberately separates sender identity from checksum
integrity: the test is malicious authority payload validation, not a claim that
a recomputed checksum authenticates a foreign sender.

Original complete checkpoints and raw packet/image copies remain owned and
unmodified until checked cleanup. Each rejection oracle compares all five parts
and real published frontiers/held/pending/authority/effect-queue state; valid

independent assertions. No rejection, confirmation, effects or successful state
is invented. Expected RED is not accepted as a passing test. Additional sender,
window and count corpus work remains Root-selected, not implied coverage here.
